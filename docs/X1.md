# X1 por personagem

Na aba **PvP → X1**, importe um arquivo `.json` de regras e use **Usar para este
personagem**: cada personagem tem o seu. O arquivo e so dados (nao executa codigo).

As regras sao lidas de cima para baixo; a primeira cujas condicoes (`se`) valem decide a
acao (`faca`). Sem `se`, a regra sempre vale (use como padrao no fim).

Condicoes:

| Chave | Exemplo | Significado |
|---|---|---|
| `minha_vida_pct` | `{"<": 30}` | vida do personagem em % |
| `meu_sp_pct` | `{">=": 50}` | SP do personagem em % |
| `vida_inimigo_pct` | `{"<": 20}` | vida do inimigo em %, quando o servidor informa |
| `distancia_inimigo` | `{">": 3, "<=": 9}` | distancia em celulas |
| `segundos_de_luta` | `{">": 60}` | tempo desde o inicio do X1 |
| `inimigo_conjurando` | `true` | inimigo conjurando habilidade |
| `inimigo_escondido` | `true` | inimigo em hide/cloak |
| `inimigo_visivel` | `false` | inimigo fora da tela |
| `habilidade_pronta` | `524` | habilidade sem recarga |
| `tenho_efeito` | `12` | efeito ativo no personagem |
| `inimigo_tem_efeito` | `12` | efeito ativo no inimigo |

Acoes: `atacar`, `habilidade` (`id`, `nivel`), `afastar` (`celulas`), `aproximar`,
`esperar` (`segundos`), `item` (`id`), `parar`.

Exemplo completo: `docs/exemplo_x1.json` (botao **Importar exemplo**). Nesta versao a
estrutura le, valida e decide a regra (`nrobot/x1_scripts.py`); a execucao no combate sera
ligada a partir do arquivo de teste.
